# Membrane Visual QC 1.0.0rc1 release notes

Status: **release preparation; manual acceptance and publication pending**.

`1.0.0rc1` is a release-hardening candidate built from the published, owner-accepted v0.9.0
baseline. It adds no feature, GUI redesign, scientific-threshold change, report schema, batch mode,
or scope expansion.

## RC hardening delta

- Re-verifies and directly pins the public PyMOL commands, five-mode batch contract, report schemas
  1.0-1.5, status/error vocabulary, CSV order, cache-v1 format, output layout, and public Python API.
- Makes the result-browser and Batch review operational error-code inventory exhaustive and
  machine-checked.
- Adds real-Qt close/reopen singleton coverage and runs both UI-polish and Windows path-hardening
  tests in the Windows CI job.
- Re-stamps the 1.x contract-freeze provenance and documents why the accepted PDBTM/OPM identity
  tolerances remain unchanged for RC compatibility.
- Adds focused RC acceptance and final-1.0 exit criteria.

## Compatibility

- v0.9.0 remains the immutable behavioral and scientific baseline.
- Existing report schemas 1.0-1.5, `mvqc-batch-plan-1.0`, `mvqc-batch-result-1.0`, `cache-v1`,
  output paths, CSV fields, command signatures, and status meanings remain unchanged.
- The supported RC upgrade method is clean replacement from the published v0.9.0 Plugin ZIP,
  followed by a full PyMOL restart. Rollback uses the verified v0.9.0 ZIP.
- GitHub Releases remains the only distribution channel; no PyPI publication is planned.

## Known limitations

The graphical validation scope remains Windows with Incentive PyMOL. Linux, macOS, and other PyMOL
distributions are not manually validated. Batch execution remains sequential on PyMOL's main
thread; history is session-only; no cache migration, source ranking, fitting, consensus, or
biological-correctness verdict is provided. See `docs/known_limitations.md`.

## Installation and upgrade

Use `docs/quick_start.md` for installation and `docs/upgrade_guide.md` for the v0.9.0-to-1.0.0rc1
clean-replacement and rollback procedure. Manual acceptance must use the exact frozen RC ZIP from
`docs/releases/1.0.0rc1_manual_acceptance.md`.
