# Membrane Visual QC v0.9.0 release notes

Status: **release preparation; not published**.

v0.9.0 is the formal public prerelease baseline intended for acceptance before `1.0.0rc1`. It
packages the five-mode review workflow and the UI/documentation work already exercised during
development, adds an explicit 1.x compatibility contract and machine-readable contract inventory,
and hardens installed-ZIP and GUI worker failure handling. Earlier real-PyMOL screenshot and
documentation sessions are not represented as formal release acceptance.

## Highlights

- Freezes the planned 1.x public command, batch-plan, report-schema, cache, output-path, status,
  outcome, and CSV compatibility boundaries.
- Adds `docs/contracts/` generated public-contract inventories with anti-drift tests.
- Prevents unexpected PDBTM cache worker exceptions from escaping Qt slots; users receive a
  traceback-free failure while diagnostic exception data remains logged.
- Extends clean installed-ZIP acceptance for isolated import, stub registration, spaces/Unicode,
  read-only installation, external cache/output state, offline behavior, and restart determinism.
- Adds the v0.8.0-to-v0.9.0 migration and exact frozen-artifact manual acceptance procedure.

## Installation and upgrade

Install the verified `MembraneVisualQC-0.9.0.zip` through PyMOL Plugin Manager using clean
replacement, then fully restart PyMOL. See `docs/quick_start.md` and `docs/upgrade_guide.md`.

## Compatibility and limitations

The manually validated graphical target remains Windows with Incentive PyMOL; Linux/macOS and
other PyMOL distributions are not yet graphically validated. Offline workflows make no network
request; only the explicit PDBTM retrieval action is network-capable. See `docs/compatibility.md`,
`docs/known_limitations.md`, and `docs/offline_and_safety.md`.
