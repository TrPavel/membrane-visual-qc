# Membrane Visual QC 1.0.0 release notes

Status: **published stable release**. `1.0.0` is the owner-accepted first stable release, published
on 2026-08-14 at https://github.com/TrPavel/membrane-visual-qc/releases/tag/v1.0.0.
**OWNER FINAL ACCEPTANCE: PASS — OWNER OBSERVED.**

`1.0.0rc1` is the owner-accepted public release-candidate baseline. No feature scope has been
added after RC1. Post-RC1 work is release hardening: frozen-evidence diff protection,
integrity-documentation coverage, exact geometry boundaries, strict JSON serialization, direct
command coverage, batch numeric boundaries, and result-browser diagnostic regression coverage.

## Compatibility and scientific boundary

The 1.x compatibility commitments remain those in [versioning_policy.md](versioning_policy.md) and
[v1.0_contract_freeze.md](v1.0_contract_freeze.md). No report schema, batch-plan contract, cache
format, CSV contract, status vocabulary, PyMOL command signature, GUI workflow, scientific
algorithm, threshold, or membrane-classification convention changed after RC1.

This remains a visual-QC and manual-review tool, not a biological-correctness verdict. The existing
scientific limitations remain in [scientific_interpretation.md](scientific_interpretation.md) and
[known_limitations.md](known_limitations.md).

## Integrity and distribution

The release uses deterministic Plugin ZIP construction, a SHA-256 sidecar, an annotated tag,
immutable historical evidence, frozen-evidence validators, and a historical-diff
guard. Details and verification commands are in
[supply_chain_integrity.md](supply_chain_integrity.md). There is no code signing, signed installer,
Sigstore attestation, SLSA provenance, cryptographic build attestation, or SBOM claim. GitHub
Releases is the only distribution channel; PyPI is not used.

## Upgrade and rollback

Use clean replacement for `1.0.0rc1` → `1.0.0`, retain user-owned outputs/cache, restart PyMOL,
and confirm the displayed version. To roll back, cleanly replace the final ZIP with the frozen
`1.0.0rc1` ZIP and restart. The owner checklist in
[releases/1.0.0_manual_acceptance.md](releases/1.0.0_manual_acceptance.md) passed all 31 items by
owner observation before publication. Immutable metadata is in
[v1.0.0_release_evidence.json](v1.0.0_release_evidence.json).
